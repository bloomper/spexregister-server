# Spexregister Server 2.0

## Overview

Spexregister Server is the second generation of the backend responsible for serving data related to Spexregister.

## Learning more

To learn more about Spexregister Server, please consult the [reference documentation][1].

## Building from source

You will need Java 21 or later to build Spexregister Server.
It is built using [Gradle][2]:

```
./gradlew build
```
